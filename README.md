# Vape247 — Product Catalog Website

React + Vite multi-page website framework for Vape247.

## Routes
- `/` — Home
- `/vape-devices/` — Vape devices category
- `/e-liquids/` — E-liquids category
- `/replacement-coils/` — Replacement coils category
- `/vape-accessories/` — Related accessories
- `/about-us/`, `/contact/`
- `/shipping-policy/`, `/returns-refunds/`
- `/privacy-policy/`, `/terms-and-conditions/`
- `/faq/`, `/blog/`, `/age-verification/`

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## SEO
Each information/category route has a unique title, meta description, primary topic, canonical URL and internal navigation. The XML sitemap and robots.txt are in `public/`.

**Domain note:** The sitemap currently uses `https://vape247.com` as a placeholder assumption. Replace it with the verified production domain before submitting the sitemap to Google Search Console.

## Important launch requirements
This repository is a front-end website framework, not a ready-to-operate regulated-products business. The product pages are category information templates; no verified product inventory, payment processing, shipping service or age-verification provider is connected.

Before enabling sales in the United States, obtain qualified legal/compliance review and verify the exact legal status of every product, including FDA marketing authorization where applicable; state and local restrictions; Tobacco 21 age and photo-ID requirements; PACT Act and carrier shipping rules; required federal/state registrations and tax obligations; payment-provider acceptance; and applicable privacy, consumer-protection and product-warning requirements. A simple age confirmation popup is not legally sufficient age verification.

Do not list products whose marketing or sale is not legally permitted in the destination jurisdiction. If Vape247 mixes/prepares e-liquids or modifies devices, additional manufacturer obligations may apply.
