# Vape247 — Accessories Storefront

A responsive React + Vite storefront concept for a US-focused accessories catalog.

## Included
- Responsive landing page and product catalog
- Category filters and product search
- Add-to-bag interactions and quantity controls
- Informational FAQ, contact section, and legal launch notes
- Vercel-friendly Vite configuration

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Important launch checklist
This repository contains a front-end demonstration, not a live commerce operation. Product entries and prices are illustrative placeholders, not verified inventory. The checkout is intentionally disabled. Before accepting orders:
1. Replace sample items with verified, lawful accessory inventory and accurate specifications.
2. Confirm applicable federal, state, and local laws, product safety and labeling requirements, shipping restrictions, and payment-provider policies.
3. Connect a compliant payment processor, tax calculation, shipping, order management, returns, and customer-support workflows.
4. Publish accurate privacy, terms, shipping, returns, and contact policies.
5. Test the complete purchase journey and mobile experience.

This demo intentionally excludes nicotine, tobacco, e-liquids, and vaping devices. Do not add restricted products without obtaining qualified legal review and confirming all applicable requirements and platform policies.
